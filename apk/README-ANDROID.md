# تطبيق المصحف المرتل للأندرويد — النسخة الشاملة لجميع الإصدارات والشاشات (`Quran-Player Universal APK`)

تمت هندسة هذا المشروع لتحويل مستودع **[Alhlhli/Quran-Player](https://github.com/Alhlhli/Quran-Player)** إلى تطبيق أندرويد أصلي (`Native WebView + WebViewAssetLoader`) يعمل بكفاءة تامة على:
- **جميع إصدارات أندرويد:** من **Android 5.0 (API 21)** وحتى **Android 15 / 16+ (API 35+)**.
- **جميع الهواتف والشاشات:** الجوالات بجميع مقاساتها (الصغيرة والكبيرة)، الهواتف القابلة للطي (`Foldables`)، الأجهزة اللوحية (`Tablets`)، وشاشات التلفزيون الذكية (`Android TV / Google TV`) مع دعم أزرار الريموت (`Media Play/Pause/Next/Prev`) والطباعة المباشرة (`PrintManager`) والمشاركة الأصلية.

## طريقة استخراج ملف `Quran-Player-Universal.apk` تلقائياً على GitHub (بدون أي برامج)
1. ارفع ملفات هذه الحزمة إلى مستودعك **[https://github.com/Alhlhli/Quran-Player](https://github.com/Alhlhli/Quran-Player)**.
2. سيقوم **GitHub Actions** تلقائياً ببناء التطبيق وتوقيعه ونشر ملف **`Quran-Player-Universal.apk`** مباشرة في قسم **Releases** وفي تبويب **Actions** خلال دقيقة واحدة.
3. أو محلياً على جهازك: شغّل `build-apk.bat` على ويندوز أو افتح المشروع في **Android Studio**.
