# 📖 مشغل القرآن الكريم

مشغّل صوتي للقرآن الكريم يعمل مباشرةً في المتصفح، يدعم اللغتين العربية والإنجليزية، ومبني كتطبيق ويب ثابت مستضاف على GitHub Pages.

🔗 **التطبيق:** [alhlhli.github.io/Quran-Player](https://alhlhli.github.io/Quran-Player/)

---

## ✨ المميزات

- 🎙️ **قرّاء متعددون** — اختر من بين مجموعة من قرّاء القرآن الكريم
- 📖 **مصاحف متعددة** — اختر الإصدار الصوتي المناسب
- 🔍 **البحث في السور** — ابحث بحرف أو حرفين أو الاسم كاملاً
- 🔄 **أوضاع التكرار** — كرّر سورة واحدة، أو المصحف كاملاً، أو أوقف التكرار
- 🔊 **التحكم في الصوت** — شريط تحكم قابل للضبط
- ⏩ **سرعة القراءة** — تغيير سرعة التشغيل
- ⏱️ **مؤقت الإيقاف التلقائي** — أوقف التشغيل بعد انتهاء السورة، أو المصحف، أو بعد مدة زمنية محددة تتراوح بين 5 دقائق و7 ساعات
- 📥 **تحميل السور** — تحميل أي سورة مباشرةً
- 📚 **تحميل المصحف كاملاً** — تحميل جميع السور دفعة واحدة
- ⭐ **المفضلة** — احفظ قرّاءك أو سورك المفضلة
- 🔖 **الإشارات المرجعية** — ضع إشارات على مواضع الاستماع
- 📊 **إحصائيات الاستماع** — تتبّع عدد السور المستمع إليها وإجمالي وقت الاستماع
- ⏳ **مؤقت العدّ التنازلي** — ضبط مؤقت مخصص
- 🌙 **الوضع الليلي** — دعم المظهر الداكن
- 🌐 **ثنائي اللغة** — واجهة كاملة بالعربية والإنجليزية

---

## ⌨️ اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| `Space` | تشغيل / إيقاف مؤقت |
| `→` | السورة التالية |
| `←` | السورة السابقة |
| `R` | تغيير وضع التكرار |
| `+` أو `=` | زيادة مستوى الصوت |
| `-` أو `_` | خفض مستوى الصوت |
| `S` | البحث في السور |

## 🚀 تشغيل المشروع محلياً

لا يحتاج المشروع إلى أي خادم أو تبعيات — فقط افتح الملف في متصفحك:

```bash
git clone https://github.com/alhlhli/Quran-Player.git
cd Quran-Player
# افتح index.html مباشرةً في المتصفح
```
